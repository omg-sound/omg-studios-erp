# 환경설정 UX 재설계 — 좌측 세로 메뉴 + 화면당 한 주제 설계

- 날짜: 2026-07-28
- 상태: 설계 확정(사용자 승인) → 구현 계획으로
- 요청: "아무리 고쳐도 환경설정이 불편하다. 이런저런 설정들이 눈에 잘 안 들어온다. 사람이 봤을 때 손이 잘 가게 배치와 레이아웃이 됐으면. render.com·vercel.com 같은 쓰기 좋은 환경설정."

## 진단 (실측, 1400px 뷰포트)

| 탭 | 페이지 길이 | 카드 | 입력칸 | 저장 버튼 | 접힌 설명 |
|---|---|---|---|---|---|
| 일반 | 2300px (2.6화면) | 4 | 28 | 8 | 8 |
| 콘텐츠 | 1773px (2.0화면) | 2 | 73 | 5 | 4 |
| 담당자 | 852px | 1 | 14 | 5 | 5 |
| 시스템 | 973px | 7 | 0 | 0 | 1 |

1. **탭 이름이 내용을 안 알려준다** — '일반·콘텐츠·담당자·시스템'은 분류자의 언어다. 룸을 고치려면 '일반'을 추측해 눌러야 한다.
2. **한 탭이 2~2.6화면** — 스크롤 없이 전체가 안 보이고, 위에 뭐가 있었는지 기억해야 한다.
3. **설정 사이 경계가 약하다** — 장소·기본 세션 시간·기본 예약 담당자가 한 카드 안에 얇은 선(`SETTING_BLOCK` border-t)으로만 나뉜다. 2026-07-09에 "섹션마다 카드+큰 제목이라 자리를 너무 차지한다"고 압축한 결과가, 이제는 반대로 **덩어리가 구분되지 않는** 문제가 됐다.
4. **저장 버튼이 흩어져 있다** — 일반 탭에만 8개. 뭘 바꾸면 어느 버튼인지 매번 찾는다.
5. **설명이 접혀 있다**(`explain()`이 `<details>`) — 판단에 필요한 정보가 클릭 뒤에 숨어 있다. Render·Vercel은 제목 바로 아래 상시 노출한다.
6. **빈도가 다른 설정이 같은 무게** — 장소·요금표(자주)와 구글 연동·웹훅(1회 설정)이 같은 크기를 차지한다.

## 채택안

### 1) 골격 = 좌측 세로 메뉴 (사용자 선택)

**`contactPanes`를 재사용한다** — 연락처·업체·그룹·매출·외주 작업자가 이미 쓰는 2단 마스터-디테일 골격이다. 새 레이아웃을 만들지 않으므로:
- 모바일 대응이 공짜다(선택 없으면 목록만, 선택하면 상세만 — 서버가 반응형 클래스를 정해 JS 0).
- 좌우 폭 드래그 조절·목록 자체 스크롤·읽기 폭 제한이 이미 구현돼 있다.
- 앱 전체가 같은 조작감을 갖는다(이 앱의 다른 '고르고 → 편집' 화면과 동일).

`widthKey`는 연락처(`clListW`)와 분리해 `setListW`를 쓴다(설정 메뉴는 짧아 더 좁은 기본값이 맞다).

### 2) 메뉴 = 손 가는 순서 (사용자 선택)

```
자주 쓰는 것
  장소            룸·외부 장소
  요금표          녹음·촬영 단가 + 분류
  작업 종류        믹싱·보컬튠 등
  예약 기본값      기본 세션 시간·예약 담당자
가끔 보는 것
  스태프 계정      로그인 허용·역할
  스튜디오 정보    사업자·로고(거래명세서)
한 번만 하는 것
  구글 연동        캘린더·Drive·연락처
  알림            청구 메일·웹훅
상태 보기
  시스템 ⚠N       백업·연동·감사 로그
```

- 그룹 헤더(자주/가끔/한 번만/상태)는 **라벨일 뿐 클릭 대상이 아니다**(연락처 초성 헤더와 같은 성격).
- 각 항목에 **한 줄 부제**를 단다 — 이름만으로는 뭐가 들었는지 모르는 현재 문제의 직접 해법.
- 시스템 항목에는 현재의 경고 개수 배지(⚠N)를 유지한다.

### 3) 오른쪽 = 한 화면 한 주제, 저장 하나 (사용자 선택)

각 화면 구성: **제목 → 설명(상시 노출) → 컨트롤 → 하단 우측 [변경사항 저장]**.

- ⚠️ **'저장'과 '액션'을 구분한다.** 통합 저장은 **값 편집**만 담는다. 추가·삭제·순서 이동·업로드·연동 테스트·백업 실행·동기화처럼 **누르는 순간 일어나는 일**은 종전대로 각자의 버튼이다(장소 추가까지 통합 저장에 묶으면 오히려 이상하다).
- 저장 버튼은 dirty 패턴(`data-dirty-form`/`data-dirty-save`/`data-dirty-hint`)을 그대로 쓴다. 바뀐 게 없으면 흐리고, 바뀌면 강조된다.
- **미저장 상태로 다른 설정 화면으로 이동하면 경고한다** — 기존 네비게이션 가드(`data-dirty-form` + beforeunload)가 이미 하는 일이라 추가 구현 없이 얻는다. (2026-07-27에 남긴 트레이드오프 "행 액션 클릭 시 미저장 유실"도 이 가드로 완화된다.)

**화면별 통합 대상**(두 폼을 하나로 합치는 것):
| 화면 | 지금 | 바꿈 |
|---|---|---|
| 예약 기본값 | `/settings/pro-minutes` + `/settings/default-booker` 두 폼 | 한 폼 + 저장 1개 |
| 알림 | `/settings/alert-webhook` + `/settings/alert-email` 두 폼 | 한 폼 + 저장 1개(테스트 발송 버튼은 액션으로 유지) |
| 스튜디오 정보 | `/settings/studio-info` + `/settings/studio-location` | 한 폼 + 저장 1개(로고 업로드는 multipart라 별도 액션) |

나머지(장소·요금표·작업 종류)는 이미 통합 저장이 있으므로 그대로. 구글 연동·시스템은 값 편집이 거의 없어 저장 버튼 없이 액션만 둔다(캘린더 선택만 저장).

### 4) 설명은 항상 보이게

`explain()`은 앱 전체가 쓰는 헬퍼라 **건드리지 않는다**. 대신 환경설정 화면에서만 쓰는 `settingDesc(text)`를 새로 만들어 제목 아래 상시 노출한다(`text-sm text-muted`). 기존 설명 문구는 **길어서 그대로 상시 노출하면 화면을 잡아먹으므로**, 각 화면에서 판단에 꼭 필요한 1~2문장으로 줄이고 세부 규칙은 문구에서 덜어낸다(덜어낸 내용은 이 문서·CLAUDE.md가 이미 갖고 있다).

## URL·호환

- 새 주소: `/settings?s=<key>` (키: `rooms`·`rates`·`tasks`·`booking`·`users`·`studio`·`google`·`alerts`·`system`). 기본값 = `rooms`.
- **옛 `?tab=` 링크는 302로 매핑**한다(코드·리다이렉트·앵커가 여러 곳에 있다): `settings`→`rooms`, `content`→`rates`, `people`→`users`, `system`→`system`.
- 기존 섹션 앵커(`#rates-section`·`#rooms-section`·`#task-types-section`)로 복귀하던 라우트들은 **해당 설정 화면 주소로** 바꾼다(화면이 하나의 주제만 담으므로 앵커가 불필요해진다).

## 권한

현행 규칙을 그대로 따른다(변경 없음): 환경설정 자체는 `requireStaff`(치프·스태프, 대표 차단). 그 안에서 **스태프 계정 관리는 치프 전용**(`requireChief`)이고 **웹훅도 치프 전용**이다. 좌측 메뉴에서 스태프가 볼 수 없는 항목은 **숨기지 않고 열되 편집 폼만 감춘다**(현행 동작 유지 — 스태프도 담당자 목록은 열람한다). 시스템 화면의 수동 백업·재동기화 같은 치프 전용 액션도 현행대로.

## 검증

- **뷰 계약 테스트**: 9개 화면이 각각 렌더되고, 좌측 메뉴에 항목·부제·시스템 경고 배지가 나오며, 화면당 값-편집 저장 버튼이 **1개 이하**인지. 옛 `?tab=` 4종이 새 주소로 302 되는지.
- **기존 기능 회귀**: 각 설정의 저장·추가·삭제 라우트는 **경로·계약을 바꾸지 않는다**(리다이렉트 목적지만 변경) — 기존 테스트(rooms·settings-bulk·rate-items 등)가 그대로 통과해야 한다.
- **실측**: 각 화면이 1화면 안에 들어오는지(1400px 기준 세로 900px 내외), 390px에서 가로 오버플로우 0.
- **육안**: 좌측 메뉴 + 대표 화면 3개(장소·요금표·시스템)를 데스크톱/모바일로 확인.

## 범위 밖

- 설정 값·동작 자체의 변경(요금 계산·권한 규칙 등) — 이번은 **배치와 레이아웃만**.
- 설정 검색(⌘K로 설정 항목 찾기) — 항목이 9개뿐이라 아직 불필요.
- 시스템 화면(읽기 전용 상태판)의 내용 재구성 — 이동만 하고 내용은 그대로.
