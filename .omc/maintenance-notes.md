**전수 조사 방법(재사용 가치 있음 — 스크립트는 scratchpad라 사라지니 요령만 기록)**
1. `module.exports` 이름 ↔ 다른 파일 등장 대조 → 오탐 많음(내부 소비 export는 정상)
2. 파일 안에서도 선언 1회뿐인 함수·상수 → 진짜 사망 후보. ⚠️`module.exports={ … , f:(v)=>normalize(v,X) }`
   처럼 **export 블록 안 화살표 함수가 상수를 참조**하면 오탐이 난다(블록을 지우고 세면 안 된다)

   반대(서버가 렌더하지만 클라이언트·CSS 어디서도 안 읽는 `data-*`)를 세면 폐지된 기능의 잔재가 드러난다.
   ⚠️오탐: 동적 조립(`data-m-${k}`)·`data-fill-target="[data-equip-…]"`처럼 **셀렉터 문자열로 읽는** 것
4. `require` 구조분해 이름 ↔ 본문 등장(고아 import). ⚠️문자열 리터럴 안의 코드 예시가 걸린다(db.js)
